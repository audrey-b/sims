# Sims Random R Distributions

Gets the names of the R random variate generating functions listed in
[`Distributions()`](https://rdrr.io/r/stats/Distributions.html).

## Usage

``` r
sims_rdists()
```

## Value

A character vector.

## Examples

``` r
sims_rdists()
#>  [1] "rbeta"     "rbinom"    "rcauchy"   "rchisq"    "rexp"      "rf"       
#>  [7] "rgamma"    "rgeom"     "rhyper"    "rlnorm"    "rmultinom" "rnbinom"  
#> [13] "rnorm"     "rpois"     "rsignrank" "rt"        "runif"     "rweibull" 
#> [19] "rwilcox"  
```
